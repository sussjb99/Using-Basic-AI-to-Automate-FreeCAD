# Using Basic AI to Automate FreeCAD


## OverView

There are currently several different ways to utilize AI to help facilitate the automation of FreeCad. However, the method I would like to discuss has the lowest barriers of entry and incurs no additional costs.

## AI Chat-Bots

The three AI chatbot interfaces I tested with this methodology were Microsoft Copilot, Google Gemini, and OpenAI's ChatGPT. Based on my results as of October 2026, the free versions of Gemini and ChatGPT both performed quite well. Unfortunately, Microsoft Copilot struggled to complete my requests successfully.

I suspect that Anthropic's Claude would also perform well at these tasks. However, because using Claude's chatbot can involve costs, I excluded it from my testing


## Belt Return

The example I will use to illustrate my methodology is the creation of a belt return.

For some odd reason, most of my belts have a tendency to flop around rather distressingly. This is likely because the belt loops on my pants are in the wrong places, or because the belts' built-in returns are not positioned where I need them. My usual solution is to create my own supplemental belt returns.

Since I own a 3D printer and have the basic skills needed to design a suitable model in FreeCAD, creating one myself would probably take an hour or two. However, either because I am exceedingly lazy or because I want to explore the capabilities of AI, I have decided to use an AI chatbot to speed up the process. I also hope to improve the functionality of my FreeCAD models so that they can more easily accommodate different belt sizes.



The process begins by measuring a few key dimensions of your existing belt.

The first measurement is the thickness of the belt. For my design, I chose an opening height equal to twice the belt thickness, allowing room for two layers of belt. Since my belt is 3.5 mm thick, the opening height is 7 mm.

The next measurement is the width of the belt, which in my case is 39.5 mm.

Finally, two additional dimensions need to be selected: the depth of the belt return and the thickness of its walls. For my design, I chose a depth of 6 mm and a wall thickness of 1.35 mm.

After providing this information to the AI, I suggest confirming that it fully understands the objective and can explain the significance of each specified parameter.

Once the first iteration is completed successfully, you can later provide the AI with additional instructions to modify the macro. For example, you can ask it to generate a built-in spreadsheet to facilitate making future fine adjustments to the belt's dimensions.

In addition, I would suggest asking the AI to create a prompt to fully document the request.

## Troubleshooting: What Happens If Something Goes Wrong?

It is unlikely that this method will work perfectly on the very first try without any issues whatsoever. Fortunately, troubleshooting and correcting problems is usually straightforward.

You have four key steps and tools for providing feedback to the AI when issues arise:

1. **Describe the issue clearly:** Explain your analysis of the generated object. Detail exactly what you see versus what you expected to see as clearly as possible.

2. **Provide a screenshot:** Take a screen capture of the model rendered in FreeCAD and share it with the AI.

3. **Share Python Console output:** Copy and paste the text from FreeCAD's Python Console. This is especially critical if the console displays error messages.

4. **Request the fix:** Ask the AI if it understands what went wrong and request an updated macro script to fix the problem.

Repeat these steps iteratively until the object renders correctly as required and the spreadsheet parameters can be modified to apply any necessary fine adjustments.


## Printing the Object

Printing the 3D-generated object created in FreeCAD is straightforward:

1. **Export the 3D model:** Select the object in FreeCAD, then go to **File** \> **Export**. Select \**STL Mesh (\*.stl .ast)* as the file format.

2. **Slice the model:** Import the exported STL file into your slicer software (e.g., PrusaSlicer, Cura, or Bambu Studio) and slice it to generate the **G-code** file.

3. **Send to printer:** Transfer the G-code file to your 3D printer.

Don’t be surprised if your first print is slightly off in terms of the required dimensions—a few test iterations are to be expected to dial in the fit.


## Post-Processing

Following a successful print, a light sanding may be required using 180-grit sandpaper. Given that my belt returns are printed in black PLA, I have found that a few strokes of a black Sharpie marker fully hide any remaining sanding marks.

# Appendix A (Beltkeeper AI Prompt)

**Macro Generation Prompt**

**Task:** Write a FreeCAD Python macro that creates a parametric 3D print model for a **Belt Keeper** using a **FreeCAD Spreadsheet Object** for parameter management.

**Requirements:**

1. **Parametric Setup (FeaturePython):**

   - Create a Spreadsheet::Sheet named "Spreadsheet" containing all driving parameters and derived expressions.

   - Build the geometry inside a Part::FeaturePython object ("BeltKeeper") with an execute(self, obj) method so that whenever values in the Spreadsheet are updated, the 3D model automatically recomputes and adjusts its dimensions.

   - Add a property link connecting BeltKeeper.Spreadsheet = sheet to enforce dynamic recomputation dependencies.

2. **Spreadsheet Parameters to Include:**

   - **User Inputs (Values & Aliases):**

     - BeltThickness: 3.5

     - BeltWidth: 39.50

     - Layers: 2

     - WallThickness: 1.35

     - KeeperDepth: 6.0

     - FilletRadius: 1.0 (Outer vertical corner fillets)

     - OuterFilletRadius: 0.3 (Entry rim roundovers)

     - InnerFilletRadius: 0.5 (Inner cavity corner fillets)

     - CutOvershoot: 0.5 (Extra length for clean Boolean subtraction)

   - **Derived Formula Cell Aliases:**

     - InnerHeight: =BeltThickness \* Layers

     - InnerWidth: =BeltWidth

     - OuterHeight: =InnerHeight + 2 \* WallThickness

     - OuterWidth: =InnerWidth + 2 \* WallThickness

     - OuterDepth: =KeeperDepth

3. **Geometry Construction Logic (execute method):**

   - Cast all values fetched from sheet.get() to float() to avoid type/unit mismatch errors.

   - **Outer Block:** Centered at X=0, Y=0, starting at Z=0, sized to OuterWidth $\\times$ OuterHeight $\\times$ OuterDepth.

   - **Inner Cutout:** Centered at X=0, Y=0, extending from Z=-CutOvershoot to Z=OuterDepth + CutOvershoot, sized to InnerWidth $\\times$ InnerHeight $\\times$ (OuterDepth + 2 \* CutOvershoot).

   - **Fillets:**

     - Filter and apply FilletRadius to vertical outer corner edges.

     - Filter and apply InnerFilletRadius to vertical inner cavity edges.

     - Filter and apply OuterFilletRadius to front/back entry rim edges (at Z=0 and Z=OuterDepth).

4. **GUI/View Setup:**

   - Set active view to axonometric/isometric and execute ViewFit after script completion.

doc = App.ActiveDocument if not doc: doc = App.newDocument("BeltKeeper")

# 2. Create Spreadsheet and setup parameters

sheet = doc.getObject("Spreadsheet") if not sheet: sheet = doc.addObject("Spreadsheet::Sheet", "Spreadsheet")

parameters = \[ ("A1", "BeltThickness", "B1", 3.5, "BeltThickness"), ("A2", "BeltWidth", "B2", 39.50, "BeltWidth"),  \# Updated width ("A3", "Layers", "B3", 2, "Layers"), ("A4", "WallThickness", "B4", 1.35, "WallThickness"), ("A5", "KeeperDepth", "B5", 6.0, "KeeperDepth"), ("A6", "FilletRadius", "B6", 1.0, "FilletRadius"), ("A7", "OuterFilletRadius", "B7", 0.3, "OuterFilletRadius"), ("A8", "InnerFilletRadius", "B8", 0.5, "InnerFilletRadius"), ("A9", "CutOvershoot", "B9", 0.5, "CutOvershoot"), \]

for name\_cell, name, val\_cell, val, alias in parameters: sheet.set(name\_cell, name) sheet.set(val\_cell, str(val)) sheet.setAlias(val\_cell, alias)

# Derived values in Spreadsheet

derived\_values = \[ ("A10", "InnerHeight", "B10", "=BeltThickness \* Layers", "InnerHeight"), ("A11", "InnerWidth", "B11", "=BeltWidth", "InnerWidth"), ("A12", "OuterHeight", "B12", "=InnerHeight + 2 \* WallThickness", "OuterHeight"), ("A13", "OuterWidth", "B13", "=InnerWidth + 2 \* WallThickness", "OuterWidth"), ("A14", "OuterDepth", "B14", "=KeeperDepth", "OuterDepth"), \]

for name\_cell, name, val\_cell, expr, alias in derived\_values: sheet.set(name\_cell, name) sheet.set(val\_cell, expr) sheet.setAlias(val\_cell, alias)

# 3. Define the Parametric Object Class

class ParametricBeltKeeper: def **init**(self, obj): obj.Proxy = self

```
def execute(self, obj):  
    \# Retrieve the document spreadsheet  
    sheet = obj.Document.getObject("Spreadsheet")  
    if not sheet:  
        return  
  
    \# Fetch computed values from spreadsheet and safely cast to float  
    outer\_w = float(sheet.get("OuterWidth"))  
    outer\_h = float(sheet.get("OuterHeight"))  
    outer\_d = float(sheet.get("OuterDepth"))  
  
    inner\_w = float(sheet.get("InnerWidth"))  
    inner\_h = float(sheet.get("InnerHeight"))  
    cut\_overshoot = float(sheet.get("CutOvershoot"))  
    fillet\_r = float(sheet.get("FilletRadius"))  
    outer\_fillet\_r = float(sheet.get("OuterFilletRadius"))  
    inner\_fillet\_r = float(sheet.get("InnerFilletRadius"))  
  
    \# Build Geometry  
    outer\_box = Part.makeBox(outer\_w, outer\_h, outer\_d)  
    outer\_box.translate(App.Vector(-outer\_w / 2.0, -outer\_h / 2.0, 0.0))  
  
    cut\_w = inner\_w  
    cut\_h = inner\_h  
    cut\_d = outer\_d + 2.0 \* cut\_overshoot  
  
    inner\_box = Part.makeBox(cut\_w, cut\_h, cut\_d)  
    inner\_box.translate(App.Vector(-cut\_w / 2.0, -cut\_h / 2.0, -cut\_overshoot))  
  
    keeper\_shape = outer\_box.cut(inner\_box)  
  
    \# Main vertical outer corner fillets  
    vertical\_outer\_edges = \[\]  
    for edge in keeper\_shape.Edges:  
        v\_points = \[v.Point for v in edge.Vertexes\]  
        is\_vertical = (  
            len(v\_points) == 2  
            and abs(v\_points\[0\].x - v\_points\[1\].x) \< 1e-3  
            and abs(v\_points\[0\].y - v\_points\[1\].y) \< 1e-3  
        )  
        is\_outer = not all(  
            abs(abs(pt.x) - (inner\_w / 2.0)) \< 1e-3 for pt in v\_points  
        )  
  
        if is\_vertical and is\_outer:  
            vertical\_outer\_edges.append(edge)  
  
    if vertical\_outer\_edges and fillet\_r \> 0:  
        keeper\_shape = keeper\_shape.makeFillet(fillet\_r, vertical\_outer\_edges)  
  
    \# Inner cavity corner fillets  
    vertical\_inner\_edges = \[\]  
    for edge in keeper\_shape.Edges:  
        v\_points = \[v.Point for v in edge.Vertexes\]  
        is\_vertical = (  
            len(v\_points) == 2  
            and abs(v\_points\[0\].x - v\_points\[1\].x) \< 1e-3  
            and abs(v\_points\[0\].y - v\_points\[1\].y) \< 1e-3  
        )  
        is\_inner = all(  
            abs(abs(pt.x) - (inner\_w / 2.0)) \< 1e-3 for pt in v\_points  
        )  
  
        if is\_vertical and is\_inner:  
            vertical\_inner\_edges.append(edge)  
  
    if vertical\_inner\_edges and inner\_fillet\_r \> 0:  
        keeper\_shape = keeper\_shape.makeFillet(  
            inner\_fillet\_r, vertical\_inner\_edges  
        )  
  
    \# Entry rim fillets  
    rim\_edges = \[\]  
    for edge in keeper\_shape.Edges:  
        v\_points = \[v.Point for v in edge.Vertexes\]  
        is\_front\_or\_back = all(  
            abs(pt.z - 0.0) \< 1e-3 or abs(pt.z - outer\_d) \< 1e-3  
            for pt in v\_points  
        )  
        is\_outer = not all(  
            abs(abs(pt.x) - (inner\_w / 2.0)) \< 1e-3 for pt in v\_points  
        )  
  
        if is\_front\_or\_back and is\_outer:  
            rim\_edges.append(edge)  
  
    if rim\_edges and outer\_fillet\_r \> 0:  
        keeper\_shape = keeper\_shape.makeFillet(outer\_fillet\_r, rim\_edges)  
  
    \# Assign updated shape to object  
    obj.Shape = keeper\_shape
```
